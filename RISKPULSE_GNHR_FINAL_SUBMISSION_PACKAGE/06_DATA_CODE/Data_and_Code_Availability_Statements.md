# RISKPULSE DATA AND CODE AVAILABILITY STATEMENTS

Data Availability Statement:
Terrain DEM rasters and sample multispectral bands are provided in local research session stores. High-frequency river gauge hydrographs and dual-polarization Sentinel-1 SAR scenes remain subject to institutional data release policies and cloud service runtime authentication.

Code Availability Statement:
The RiskPulse research software architecture, calculation contracts, and automated unit test suite reside within the project source repository. Research execution tools are available for academic peer review upon request.
