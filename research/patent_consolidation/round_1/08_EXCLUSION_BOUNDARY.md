## 1. EXPLICIT GENERIC FEATURE EXCLUSION LIST

To prevent patent claims from becoming a collection of generic prior-art features, the following elements are **EXPLICITLY EXCLUDED** from the proposed core invention boundary:

1. Generic GIS portal rendering or map visualization.
2. Generic satellite imagery acquisition or sensor hardware.
3. Generic Natural Language Processing (NLP) or social media keyword scraping.
4. Generic hazard classification or weather forecasting.
5. Generic administrative polygon map drawing.
6. Generic selective database recomputation (`C07` / `EP3622411B1`).
7. Generic software build dependency invalidation (`US7441230B2`).
8. HPSDMA-specific database schemas or REST API endpoints.
9. Flutter / Dart UI widgets, dashboards, or mobile screens.
10. Google Earth Engine (GEE), Gemini LLM, or Sentinel-2 specific APIs.
