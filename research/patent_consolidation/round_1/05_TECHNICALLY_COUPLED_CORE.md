## 1. THE SMALLEST INDISPENSABLE TECHNICALLY COUPLED CORE

$$\text{Observation Mutation} \xrightarrow[\text{Interpretation}]{\text{Semantic}} \text{Event Hypothesis} \xrightarrow[\text{Crosswalk}]{\text{Spatial-Admin}} \text{Transitive 6-Layer DAG Closure} \xrightarrow[\text{Version Store}]{\text{Bitemporal}} \text{Auditable Risk State } (V_k)$$

1. Ingestion of an observation mutation (text, telemetry, or remote-sensing raster).
2. Semantic interpretation and multi-source event hypothesis clustering.
3. Spatial event boundary closure and proportional administrative unit crosswalk attribution.
4. Transitive 6-layer DAG closure calculation updating shared downstream administrative/risk nodes.
5. Cross-event and cross-region branch isolation preserving unaffected event subgraphs.
6. Bitemporal state versioning ($V_1..V_k$) preserving immutable historical snapshots.
