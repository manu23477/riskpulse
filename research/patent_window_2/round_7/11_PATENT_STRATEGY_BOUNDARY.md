## 1. WHAT SHOULD NOT BE CLAIMED AS SINGLE-REFERENCE NOVEL

Based on single-reference prior-art evidence, the following atomic features are known in prior art and **SHOULD NOT BE CLAIMED AS INDEPENDENT NOVEL INVENTIONS**:
1. Standalone satellite image feature extraction (`US8548248B2`).
2. Standalone GIS hazard map rendering or buffer creation (`US10036650B2`).
3. Standalone administrative unit loss map generation (`CN119903394B`).
4. Standalone generic selective recomputation (`EP3622411B1`).
5. Standalone software build dependency invalidation (`US7441230B2`).
6. Standalone bitemporal stream versioning (`US20200379978A1`).
